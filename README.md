# 経営意思決定フレームワーク(中小企業向け)

中小企業の経営者が、日々の経営判断を「勘」ではなく「基準」で下すためのドキュメント集です。
迷ったときに開き、当てはめ、決める。そのための実用ハンドブックとして使ってください。

## 構成

| # | ファイル | 領域 | 主な用途 |
|---|---|---|---|
| 1 | [docs/01-strategy.md](docs/01-strategy.md) | 経営戦略・事業方針 | やる/やらないの選別、事業ポートフォリオ判断 |
| 2 | [docs/02-finance.md](docs/02-finance.md) | 財務・投資判断 | 投資可否、資金調達、撤退ライン |
| 3 | [docs/03-organization.md](docs/03-organization.md) | 組織・人事 | 採用・評価・解雇、権限委譲 |
| 4 | [docs/04-sales-marketing.md](docs/04-sales-marketing.md) | 営業・マーケティング | 価格、顧客選別、販路 |
| 5 | [docs/05-decision-checklist.md](docs/05-decision-checklist.md) | 横断チェックリスト | 重大判断時の最終確認 |

## 使い方

1. **判断する前にひらく**: 直感で動く前に、該当領域のドキュメントの「判断基準」セクションに目を通す。
2. **チェックリストを通す**: 重大判断(投資 > 月商10%、人員 ±10%、新規事業) は必ず `05-decision-checklist.md` を通す。
3. **書き換える**: 自社固有の閾値(例: 撤退ライン、採用基準)を実数値に書き換えて運用する。テンプレではなく自社の経典にする。

## 設計思想

- **基準は数値で**: 「成長性が高い」ではなく「3年で粗利2倍」と書く。
- **決め切れない判断は構造で殺す**: 「迷ったらやらない」「迷ったら小さく試す」を先に決めておく。
- **撤退条件を先に書く**: やる前に、やめる条件を明文化する。
- **属人化を避ける**: 経営者が倒れても、この基準で代行者が判断できるレベルを目指す。

---

中小企業は意思決定の速さが武器です。基準を持っている経営者は速く、持っていない経営者は迷う。このリポジトリはその差を埋めるためのものです。
