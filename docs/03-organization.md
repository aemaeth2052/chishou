# 03. 組織・人事の判断基準

人は最大の資産であり、最大のコストでもある。情緒で採り、情緒で評価し、情緒で別れると、組織は壊れる。
この章は、人事を「気持ち」ではなく「基準」で動かすためのルール。

---

## 1. 採用判断の3原則

### 原則1: 「足りないから採る」のではなく「役割が定義できたから採る」

採用前に必ず以下を文書化する。曖昧なら採らない。

```
募集ポジション: ___________
このポジションが解くべき課題: ___________
1年後の到達ゴール(数値): ___________
このポジションが必要な根拠(現状の損失/機会): ___________
権限と責任の範囲: ___________
直属上司: ___________
給与レンジ: ___ 〜 ___ 万円
評価指標(3つまで): ___________
```

### 原則2: スキル < カルチャー < 誠実性

- **誠実性**: 嘘をつかない、約束を守る、責任を逃げない。これが欠けたら他がどれだけ良くても不採用。
- **カルチャー**: 自社の価値観と合うか。後から教えられない。
- **スキル**: 教えられる。今足りなくても伸びる人なら可。

**逆ピラミッドで判断する**: 誠実性で落とせる人は迷わず落とす。

### 原則3: 採用は「2人で会う」「2回以上会う」

経営者一人の直感に頼らない。最低でも別の社員(または信頼できる外部)の評価を入れる。
2回会うと、初回の印象とのズレで本性が見える。

---

## 2. 採用してはいけない人(レッドフラグ)

面接で以下に該当する兆候が見えたら、能力に関係なく見送る。

- [ ] 前職の上司・同僚を強く悪く言う(自社でも同じことをする)
- [ ] 約束した時間に遅刻し、言い訳が長い
- [ ] 質問に対して、自分が話したいことを話す(対話できない)
- [ ] 給与・条件の話を最初から細かく詰めてくる(貢献より受け取りに関心)
- [ ] 「すぐ辞める可能性のある」サイン(短期離職の繰り返し、転職理由が他責)
- [ ] 経営者の前と他の社員の前で態度が露骨に違う

中小企業は1人の採用ミスが組織全体を壊す。**迷ったら採らない**を徹底する。

---

## 3. 試用期間と本採用の判定基準

試用期間(3〜6ヶ月)中に以下を評価。1つでもNGなら本採用しない。

| 評価項目 | 合格基準 |
|---|---|
| 業務遂行 | 任された範囲の8割を、催促なしに完了している |
| 学習姿勢 | 同じミスを繰り返さない、フィードバックを受け止める |
| 人間関係 | 既存メンバーとの摩擦・トラブルがない |
| 誠実性 | 報連相が機能している、隠し事の兆候がない |
| 価値観 | 自社の行動規範と矛盾しない |

**試用期間の延長は1回まで**。それでも判断がつかないなら本採用しないほうが、本人にとっても誠実。

---

## 4. 評価制度のシンプル設計

中小企業で複雑な評価制度は機能しない。以下3軸で十分。

```
評価軸 = (①成果) × (②行動) × (③役割期待充足度)

①成果        : 担当領域のKPI達成度。数値で測れるもの
②行動        : 行動規範(クレド)に沿っているか。具体エピソードで判定
③役割期待   : 等級ごとの期待値(後輩育成、専門性、自走度)
```

### 評価運用のルール

- **半年に1回**: フォーマル評価(昇給・賞与に反映)
- **月1回**: 1on1(15〜30分、評価ではなく対話)
- **評価のフィードバックは必ず対面**: 文書だけで済ませない
- **昇給は「過去の頑張り」ではなく「次の役割への期待」で決める**
- **報酬の格差は隠さず根拠を説明できる状態にする**(本人開示は別問題、社内秩序の話)

## 5. 権限委譲の判断

経営者がボトルネックになっている兆候:

- [ ] 経営者の決裁待ちで業務が止まる案件が週3件以上ある
- [ ] 経営者が休むと売上が落ちる
- [ ] 細かい承認(数万円の発注、休暇許可)で時間が溶けている
- [ ] 「自分でやったほうが早い」と思って自分でやっている

3つ以上当てはまれば、即座に権限委譲を進める。

### 委譲フレーム

```
業務をリスト化
    │
    ▼
①その業務は経営者にしかできないか?
    └─ Yes → 自分でやる(戦略、最終決裁、対外交渉のキー、社員の評価)
    └─ No  → 次へ
    │
    ▼
②任せる相手にスキルがあるか?
    └─ Yes → 即委譲。失敗の許容額を決めて任せる
    └─ No  → 次へ
    │
    ▼
③育てる価値があるか?
    └─ Yes → ペアで3回やった後に委譲。フォローは継続
    └─ No  → 外注化 or 廃止
```

**委譲のルール**: 任せたら口を出さない。報告のタイミングと撤回条件だけ決める。

## 6. 離職を防ぐサイン(早期検知)

退職する社員は、辞表を出す3〜6ヶ月前から兆候が出る。

| 兆候 | 解釈 |
|---|---|
| 1on1で話す内容が浅くなる | 信頼の低下、または既に決意済み |
| 残業時間が急に減る(本人比) | 副業・転職活動の可能性 |
| 有給消化のペースが上がる | 面接 or 退職前の整理 |
| 新しい業務への意欲を示さない | 組織への期待を失った |
| 同僚との雑談が減る | 孤立、または線引き |

兆候を見つけたら、1on1で**「最近どう?」ではなく「何か変化があった?」**と踏み込んで聞く。

## 7. 解雇・契約解除の判断

解雇は最後の手段。ただし「すべきときにできない」のは経営者の怠慢。

### 解雇を検討すべきケース
- 重大な就業規則違反(横領、ハラスメント、機密漏洩)→ 即時、ただし手続きは厳格に
- 業務遂行能力が著しく低く、改善指導を3ヶ月以上行っても改善が見られない
- 周囲を腐らせる存在(他の優秀な社員が辞める要因になっている)

### 解雇前の必須プロセス
1. 問題行動の**書面記録**を残す(日時・内容・指導内容)
2. 改善指導を**3回以上**、書面で行う
3. 改善計画書(PIP)を作成し、本人と合意
4. それでも改善されない場合、**社労士・弁護士に相談してから**実行

**情で残すと組織全体が劣化する**。逆に、感情で切ると訴訟リスクと評判リスクで会社が傷つく。基準とプロセスで動く。

---

## 8. 経営者の自己ルール

組織は経営者を映す鏡。以下を自分に課す。

- [ ] 社員の前で他人(顧客、取引先、社員)の悪口を言わない
- [ ] 自分のミスは自分で公表する(隠したら見抜かれる)
- [ ] 報酬は業績連動。業績が悪い期は経営者報酬から先に削る
- [ ] 社員より先に出社・後に退社、ではなく**社員より先に決断・後に責任**
- [ ] 「ありがとう」と「ごめん」を社員に言える
