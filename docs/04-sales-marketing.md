# 04. 営業・マーケティングの判断基準

中小企業の営業は「数を打つ」のではなく「打つべき相手を選ぶ」ゲーム。
この章は、価格・顧客・販路の3点を、感覚ではなく基準で決めるためのもの。

---

## 1. 顧客の選別(顧客ランクづけ)

すべての顧客を平等に扱うのは、優良顧客への裏切り。以下の基準でA/B/Cにランクづける。

| ランク | 売上シェア | 粗利率 | 対応工数 | 戦略 |
|---|---|---|---|---|
| **S** | 上位5% | 自社平均以上 | 適正 | VIP対応、専任担当、深耕 |
| **A** | 上位5〜25% | 自社平均以上 | 適正 | 関係強化、Sへ昇格を狙う |
| **B** | 中位50% | 自社平均±5pt | 適正 | 標準対応 |
| **C** | 下位20% | 自社平均未満 | 過剰 | 値上げ交渉 or 縁切り |

### Cランク顧客への対応

「悪い顧客は悪い社員と同じ」。以下を順に試す。

1. 値上げ交渉(現行価格×1.2〜1.5倍を提示)
2. 受注条件の引き上げ(最低発注量、前金、納期延長)
3. 上記をのまない場合は契約終了

Cランクを切ると、空いた工数でA・S顧客への対応が厚くなり、結果として売上は下がっても利益は増えることが多い。

---

## 2. 価格設定の3つの観点

価格は「コスト + 利益」で決めない。**顧客が払える価値**で決める。

```
①コスト基準  : 原価 + 必要利益。最低ライン。これを下回ったら受注しない
②競合基準  : 競合の価格帯。安易に合わせない、差別化の材料にする
③価値基準  : 顧客が得る効果(売上増、コスト削減、時間節約)から逆算
```

### 値付けのルール

- **原価率は40〜60%を目安**(業界による)。これを上回るなら値上げか撤退。
- **「いくらなら払える?」と聞くより、「これがなかったら何に困りますか?」と聞く**。後者から価格根拠が見える。
- **値引きは「条件交換」で**: 値引きするなら、必ず代わりに何かをもらう(発注量、前金、長期契約、紹介)。
- **3社相見積もりで最安を狙う仕事は受けない**。価格でしか勝負できない仕事に明日はない。

---

## 3. 受注可否の判断

新規受注のたびに、感覚ではなくチェックリストで判定。

```
□ 粗利率が自社基準(例: 40%)を上回る
□ 既存業務を大きく圧迫しない(工数 < 10人日 or リソースに余裕がある)
□ 顧客のリスク(支払遅延歴、無理難題、レビュー悪)が許容範囲
□ 自社の強み・実績を活かせる(または将来の強みに繋がる)
□ 期日が現実的(無理な短納期に飛びつかない)
□ 失注しても来期の売上計画に致命傷を与えない(=断る選択肢がある)

5つ以上Yes → 受注
3〜4つYes → 条件交渉(価格、納期、範囲)
2つ以下     → 丁寧に断る
```

## 4. 顧客獲得チャネルの優先順位

中小企業は「いいチャネルを1つ」極めるほうが、「全方位やる」より遥かに効く。

### 優先順位の原則
1. **既存顧客のリピート・アップセル**(獲得コストほぼゼロ)
2. **既存顧客からの紹介**(獲得コスト低、信頼ベース)
3. **特定領域での実績・コンテンツ発信**(時間はかかるが資産になる)
4. **業界内ネットワーク・パートナー連携**
5. **広告(リスティング、SNS等)**(計測できるならOK、できないなら避ける)
6. **飛び込み・テレアポ**(最後の選択肢、効率が悪い)

### チャネル選定のチェック
- そのチャネルで月10件以上のリードを取れる見込みがあるか
- 獲得コスト(CAC) < 顧客生涯価値(LTV)の3分の1 になっているか
- そのチャネルに使うコストは、撤退しても致命傷にならないか

## 5. 広告・販促費の上限

販促費の暴走は中小企業の典型的な失敗。**事前に上限を決める**。

| 指標 | 目安 |
|---|---|
| 販促費 / 売上 | 業界平均の±2pt以内 |
| 顧客獲得コスト(CAC) | 顧客LTVの1/3以下 |
| 1キャンペーンの予算 | 月商の3%以内(失敗しても痛まない額) |
| 効果測定期間 | 開始時に決める(例: 3ヶ月)。以降の継続可否は数字で判断 |

**広告代理店に丸投げしない**。経営者がCPC・CPA・コンバージョン率を1ヶ月で説明できないなら、外注すべきでない。

## 6. 提携・パートナーシップの判断

「良さそうな提携話」の9割は時間の無駄。以下を満たすものだけ進める。

- [ ] 自社の強み × 相手の強み で、両方の顧客に新しい価値を提供できる
- [ ] 役割分担と利益配分が**契約書に書ける**レベルで明確
- [ ] 解消条件が事前に合意できる(出口戦略がある)
- [ ] 相手企業の財務・評判・経営者の人物に問題がない
- [ ] 既存顧客・既存パートナーとのコンフリクトがない

**握手で始めた提携は、握手で終わるか、訴訟で終わる**。必ず文書化する。

## 7. 営業活動のKPI

「気合と根性」ではなく数字で営業を管理する。

| KPI | 計測頻度 | 改善方向 |
|---|---|---|
| 商談数 | 週次 | 商談の入口を絞れているか(Cランク見込みを切る) |
| 商談 → 提案率 | 月次 | 60%以上を目指す |
| 提案 → 受注率 | 月次 | 業界・商材により30〜50% |
| 平均受注単価 | 月次 | 上昇傾向か(値上げ・アップセル余地) |
| 受注リードタイム | 月次 | 短縮できれば営業効率が上がる |
| 顧客あたりLTV | 四半期 | 上昇傾向か(関係深化) |

**全部見るのではなく、3つに絞る**。最も改善余地が大きいKPIを毎月の主戦場にする。

## 8. ブランド・評判の判断

中小企業ほど評判で生きている。以下を意識する。

### やるべきこと
- 顧客満足を年1回はアンケート等で計測する(NPSなど)
- 既存顧客から「紹介したくなる体験」を意図的に作る
- 良い口コミは集めて公開する(許可を取る)

### やってはいけないこと
- レビューの自作自演、サクラ
- 不満を持つ顧客を放置(SNSで拡散される前に対応)
- 過剰な約束(できないことを「できます」と言う)→ 短期売上は立つが長期で死ぬ
- 価格を下げて顧客層を変える(既存顧客が離れる)

**信用は積み上げに10年、失うのに1日**。意思決定のたびにこの言葉を思い出す。
