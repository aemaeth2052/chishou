# 用語集・固有名詞辞書

このファイルは、議事録(特に音声文字起こし)を Claude が**正しく**整形・修正するための「会社固有の知識」をためる場所。
音声認識は固有名詞・社内用語・人名を高確率で誤変換する。ここに正解を登録しておくほど、Claude の修正精度が上がる。

## 運用ルール
- 新しい固有名詞・略語・誤変換パターンが出たら追記する。
- 「要確認」の項目はユーザーが埋める。Claude は推測で確定させない。
- Claude は議事録を整形するとき、**必ずこのファイルを最初に参照**し、表記を揃える。
- glossary に無い人名・社名が議事録に出たら、推測で確定せず「(要確認: ○○?)」と注記する。
