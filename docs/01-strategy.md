# 01. 経営戦略・事業方針の判断基準

「やる/やらない」「広げる/絞る」「続ける/撤退する」を決めるための基準集。

---

## 1. 事業を評価する5つの軸

新規事業・既存事業の継続判断は、以下5軸で点数化する(各5点満点、合計25点)。

| 軸 | 問い | 5点の状態 | 1点の状態 |
|---|---|---|---|
| **市場性** | 市場は伸びているか、十分大きいか | 年率10%以上で成長、TAM > 100億円 | 縮小、ニッチすぎて天井が見える |
| **自社適合** | 自社の強み(人・技術・顧客基盤)を活かせるか | 既存資産で7割実行可能 | ゼロから能力構築が必要 |
| **収益性** | 粗利率は高いか、固定費を吸収できるか | 粗利率40%以上 | 粗利率20%未満、または赤字 |
| **競合優位** | 続けるほど他社に勝てる構造か | 参入障壁あり、リピート/口コミが効く | 価格でしか戦えない |
| **撤退容易性** | 失敗したときに身軽に降りられるか | 投下資本が小さい、人を抱え込まない | 設備・長期契約・専属人員でロック |

**判断ライン**:
- **20点以上** → やる
- **15〜19点** → 小さく試す(投資額を月商の5%以内に)
- **15点未満** → やらない、または既存事業なら撤退検討

---

## 2. 「やらないこと」を決める

中小企業の最大のリスクは「あれもこれもやる」こと。以下に該当する話は、儲かりそうでも断る。

- [ ] 自社の強みと無関係な機会(知人の紹介、流行り、補助金狙いだけの事業)
- [ ] 経営者が現場に張り付かないと回らない仕組み
- [ ] 既存の主力事業から経営者の時間を10%以上奪う案件
- [ ] 売上は立つが粗利率が既存事業を下回る仕事
- [ ] 「断れない相手」からの依頼で採算が合わないもの

**原則**: 機会損失より、リソース分散による主力事業の劣化のほうが致命的。

---

## 3. 集中と分散の判断

```
売上の特定顧客/特定商品への依存度
├─ 1社で50%超 → 危険。分散を急ぐ(脱・下請け、新規開拓)
├─ 1社で30〜50% → 注意。代替顧客の育成を始める
└─ 1社で30%未満 → 健全
```

ただし**創業3年以内**は集中したほうがよい。リソースが薄く、分散は実質的に「どれも中途半端」を意味する。

---

## 4. 撤退ライン(事前に決める)

新規事業・新製品を始めるときは、**始める前に**撤退条件を文書化する。後から決めるとサンクコストに引きずられる。

### テンプレート

```
事業/プロジェクト名: ___________
開始日: ___________
撤退判定日: 開始から ___ ヶ月後
撤退条件(いずれかに該当):
  □ 累積赤字が ___ 万円を超えた
  □ 月次売上が ___ 万円に届かない月が3ヶ月連続
  □ 想定していた主要KPI( ___ )が目標の50%未満
  □ 主力事業の売上/利益が前年比 ___% 以上低下した
撤退時の処理担当: ___________
```

---

## 5. 経営者が「決める」前に通す3つの問い

すべての戦略判断の前に、紙に書いて答える。

1. **3年後にこの判断を振り返ったとき、誇れるか?**
   (短期の利益のために、長期の信用を毀損していないか)
2. **明日、自分が倒れても、この判断は正しいまま残るか?**
   (経営者の体力・カンに依存していないか)
3. **これは「やりたい」のか「やるべき」なのか?**
   (情緒と論理を分ける。両方Yesなら強い、片方だけなら要再考)

---

## 6. 戦略レビューの頻度

| サイクル | 見るもの |
|---|---|
| 月次 | KPI、撤退ラインへの距離 |
| 四半期 | 5軸スコアの再評価、競合の動き |
| 年次 | ミッション・ビジョン、3年計画の修正 |

戦略は「立てる」ものではなく「更新する」もの。立てっぱなしは戦略ではない。
