# 02. 財務・投資判断の基準

中小企業の倒産原因の9割は資金繰り。「黒字倒産」という言葉が示す通り、利益ではなくキャッシュで死ぬ。
この章は、現金を守りながら成長するための判断基準。

---

## 1. 死守する財務指標(月次で確認)

| 指標 | 安全圏 | 注意 | 危険 |
|---|---|---|---|
| **手元現預金** | 月商の6ヶ月分以上 | 3〜6ヶ月分 | 3ヶ月分未満 |
| **自己資本比率** | 30%以上 | 15〜30% | 15%未満 |
| **借入金月商倍率** | 6ヶ月以下 | 6〜10ヶ月 | 10ヶ月超 |
| **流動比率** | 150%以上 | 100〜150% | 100%未満 |
| **粗利率** | 業界平均+5pt | 業界平均±5pt | 業界平均-5pt未満 |

**危険ゾーンに2項目以上入ったら、新規投資を凍結し、資金繰り改善を最優先**にする。

---

## 2. 投資可否のフロー

```
投資案件の発生
    │
    ▼
①金額は月商の何%か?
    ├─ 1%未満     → 担当者決裁(報告のみ)
    ├─ 1〜5%      → 通常稟議
    ├─ 5〜20%     → 経営者決裁 + 本ドキュメント全項目チェック
    └─ 20%超      → 取締役会・税理士・主要株主への事前相談必須
    │
    ▼
②投資後も「手元現預金 ≥ 月商3ヶ月分」を維持できるか?
    ├─ Yes → 次へ
    └─ No  → 却下 or 規模縮小・分割実施
    │
    ▼
③回収期間の見積もり
    ├─ 設備投資     → 3年以内に投下資本回収
    ├─ ソフト投資    → 1.5年以内に回収
    ├─ 人件費投資    → 1年以内に粗利増で吸収
    └─ R&D・実験    → 上限額のみ決め、回収を求めない
    │
    ▼
④失敗シナリオで会社は存続できるか?
    ├─ 全損しても3ヶ月分の現預金が残る → 実行
    └─ 残らない                       → 規模を半分以下に
```

---

## 3. ROI/回収期間の計算式

### シンプル回収期間
```
回収期間(年) = 投資額 ÷ 年間追加キャッシュフロー
```
- 中小企業は割引率を細かくいじるより、**シンプル回収期間 < 3年**を基準にする方が運用しやすい。

### 投資判断の3つのシナリオ
楽観・標準・悲観の3シナリオで計算し、**悲観シナリオでも資金ショートしない**ことを確認する。

| シナリオ | 売上見込み | 判断 |
|---|---|---|
| 楽観 | 計画の120% | 上振れの嬉しい誤算 |
| 標準 | 計画通り | 期待値 |
| 悲観 | 計画の60% | これでも生き残れるか |

---

## 4. 資金調達の優先順位

```
1. 自己資金(留保利益)         ← コストゼロ、ただし機会損失あり
2. 売掛金回収の早期化・在庫圧縮  ← 既存資産から現金を絞り出す
3. 政府系金融機関(日本公庫等)  ← 金利安、長期、保証協会枠を温存
4. 信用保証協会付き融資         ← メイン銀行から
5. プロパー融資                ← 信用力がついてから
6. ファクタリング・短期借入     ← 緊急時のみ。常用すると財務を蝕む
7. エクイティ調達              ← 経営権・配当方針への影響を熟考
```

**借りるなら晴れの日に**: 業績がいいときに調達枠を確保しておく。雨の日に借りようとしても貸してくれない。

---

## 5. コスト削減の優先順位

「経費を見直そう」と漠然と言わない。順番がある。

1. **撤退コスト**: 赤字事業・不採算顧客から降りる(最大インパクト)
2. **固定費**: 家賃・リース・サブスク・保険(契約見直しで効く)
3. **間接人件費**: 業務の自動化・外注化(直接人件費は最後)
4. **変動費**: 仕入交渉・歩留まり改善
5. **直接人件費**: ここに手を付けるのは最後の最後。手を付けるなら経営者報酬から先

**禁忌**: 削っていいコスト/絶対に削ってはいけないコストを混同しない。
- 削っていい: 過剰な接待、形式的な広告、惰性のサブスク
- 削ってはいけない: 顧客満足に直結する品質、社員の安全、税理士・社労士などのプロ報酬

## 6. 値上げ判断

中小企業の収益改善で最も効くのは値上げ。ただし基準を持つ。

### 値上げを検討すべきサイン
- [ ] 原価率が3年前と比べて5pt以上上昇
- [ ] 受注を断っている、納期が伸びている(需要 > 供給)
- [ ] 競合の値段が自社より高い
- [ ] 顧客から「他より安い」と言われたことがある
- [ ] 新規客の獲得に困っていない

3つ以上当てはまれば値上げ実施。

### 値上げ実施時のルール
- 既存顧客には**3ヶ月前**に通知
- 全顧客一律ではなく、**A/B/Cランク別**に幅を変える(下位ランクは大幅、上位は小幅 or 据え置き)
- 値上げで離反する顧客が出ることを織り込む(売上の10〜15%離反でも、粗利は増えるよう設計)

---

## 7. 撤退・損切りのライン

| 状況 | 判断 |
|---|---|
| 単月赤字が3ヶ月連続 | 原因分析(一時的か構造的か) |
| 単月赤字が6ヶ月連続 | 改善計画+期限を設定。期限を切る |
| 累積損失が想定の1.5倍超 | 撤退検討に入る |
| 累積損失が想定の2倍超 | 即時撤退 |
| 主力事業の利益で穴埋めしている期間が1年超 | 即時撤退 or 抜本改革 |

「あと少しで黒字化」は最も危険な言葉。**期限を切らない希望は経営判断ではない**。

---

## 8. 月次でやること(財務ルーティン)

毎月、以下を経営者自身の目で確認する(税理士に丸投げしない)。

- [ ] 試算表(P/L・B/S)を当月10営業日以内に確認
- [ ] 資金繰り表を**3ヶ月先**まで更新
- [ ] 売掛金の年齢表(滞留チェック)
- [ ] 在庫(滞留・陳腐化)
- [ ] 主要KPI(顧客別売上、粗利率、新規/リピート比率)
- [ ] 危険指標(§1)が悪化していないか

数字を見続ける経営者だけが、早く異変に気づける。
