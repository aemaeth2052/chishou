# 05. 重大判断の最終チェックリスト

投資、新規事業、人員の大幅増減、提携、撤退——会社の方向を決める判断は、**このリストを通してから決定する**。
書き出すだけで、9割の悪い意思決定は止められる。

---

## A. 判断の入口(全判断共通)

```
□ この判断は、いつまでに決めなければならないか?(締切の根拠)
□ 「決めない」という選択肢は検討したか?
□ 1週間延期して情報収集したら、判断は変わるか?
□ 同じ判断を、信頼できる先輩経営者・税理士・配偶者に話したか?
```

**急ぎの判断ほど間違える**。「今すぐ決めてください」と迫られる話の8割は、断っても損しない。

---

## B. 数字チェック

```
□ この判断で動く金額は、月商の何%か? __________
□ 失敗したとき、現預金は月商の何ヶ月分残るか? __________
□ 楽観・標準・悲観の3シナリオで試算したか?
□ 悲観シナリオでも会社は存続するか?
□ 投下資本の回収期間は何年か? __________(設備3年、ソフト1.5年が目安)
□ 既存事業の利益・キャッシュフローを毀損しないか?
```

数字が書けない判断は、まだ判断する段階に来ていない。

---

## C. 戦略整合性

```
□ この判断は、自社のミッション/3年計画と整合するか?
□ 自社の強み(人・技術・顧客基盤)を活かせるか?
□ 経営者の時間を、どれだけ奪うか?(月____時間)
□ それは主力事業から奪っても許容できるか?
□ 「やりたい」だけでなく「やるべき」と言えるか?
```

---

## D. 撤退・リスクの設計

```
□ 撤退条件を、開始前に文書化したか?
   - 撤退判定日: ___ ヶ月後
   - 撤退条件: __________
□ 失敗したときの最大損失額は? __________
□ その損失を引き当てるキャッシュ・信用余力はあるか?
□ 関係者(社員、家族、取引先)への波及を整理したか?
□ 訴訟・法的リスク(契約、知財、労務)はないか?
```

---

## E. 関係者・信義

```
□ この判断によって不利益を被る関係者は誰か?
□ その関係者にどう説明するか、想定問答を作ったか?
□ 既存顧客・既存社員への約束に反していないか?
□ 自分が逆の立場(社員、顧客)だったら、どう感じるか?
□ 公にされて困らない判断か?(新聞に載っても説明できるか)
```

---

## F. 経営者自身の状態

意思決定の質は、経営者のコンディションに直結する。

```
□ 直近1週間、十分睡眠を取れているか?(平均6時間未満なら判断を遅らせる)
□ 直近、感情を強く揺さぶる出来事はなかったか?(怒り・恐怖・焦りは判断を歪める)
□ この判断を、勢いではなく構造で決めようとしているか?
□ 「自分が正しいと証明したい」気持ちが入っていないか?
□ 反対意見を本気で聞く心の余裕があるか?
```

睡眠不足、感情の激しい揺れ、見栄。この3つが揃った状態での重大判断は、ほぼ確実に間違える。

---

## G. 最終判断のフロー

```
すべての項目に答えた後...
    │
    ▼
①Bの数字、Dの撤退条件が書けたか?
    └─ No  → まだ決めない。情報を集める
    └─ Yes → 次へ
    │
    ▼
②C・Eで重大な懸念は残っていないか?
    └─ あり → 懸念を解消するか、案件を断る
    └─ なし → 次へ
    │
    ▼
③Fの状態は良好か?
    └─ No  → 1週間後に再判定
    └─ Yes → 次へ
    │
    ▼
④決定する
    │
    ▼
⑤決定の根拠を、このチェックリストとともに**文書として残す**
   - 半年後に振り返るための材料
   - 判断ミスのパターンを学ぶための資産
```

---

## H. 判断の振り返り(四半期ごと)

過去の重大判断を、以下の観点で振り返る。

| 判断 | 結果 | 想定との差異 | 何を学んだか |
|---|---|---|---|
| (例)A工場への500万円投資 | 12ヶ月で回収予定→18ヶ月かかった | 楽観シナリオに引きずられた | 標準シナリオを基準に判断する |
| | | | |
| | | | |

**判断の質は、振り返りでしか上がらない**。当たった判断、外れた判断、両方を記録する。

---

## I. 「これだけは破らない」最終ルール

迷ったとき、以下に立ち返る。

1. **現金が3ヶ月分を切る判断はしない**
2. **撤退条件を決めずに始めない**
3. **誠実性に問題のある相手と組まない・採らない**
4. **数字で説明できない判断はしない**
5. **疲れているとき、怒っているときに重大判断をしない**
6. **「みんなやってるから」「もったいないから」を理由にしない**
7. **判断は文書に残し、半年後に振り返る**

経営に必勝法はない。だが、**致命傷を避ける方法はある**。それがこのチェックリスト。
