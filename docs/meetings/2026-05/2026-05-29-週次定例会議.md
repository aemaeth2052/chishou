## 決定事項

### 1. 情報共有(サイボウズ / 共有フォルダ / DeskNets)
- **第一元商が入る共有フォルダは6月いっぱいで閉じる**(7月頭から第一社員は基本使わない)。
- グループ各社が共有フォルダ(=若松2階サーバー)を使い続けるなら**有料化**(「うちのサーバーという商品」)。各社がバラバラのクラウドに散ると情報共有が崩れるため、ここがアドバンテージ。
- **DeskNets は廃止**(年約24万、活用されていないアカウントまで課金)。メール機能はサイボウズへ移管。
- **サイボウズのアカウント = 社員全員**(給食パート・掃除パート・作業員は除く。職長に上がる作業員は持つ)。
- 使い方:まず**連絡網**を整える。組織図(階層1=経営陣、2=所長級、3・4=その下)を完成させればサイボウズの既存機能でカスタマイズ不要。**会議室機能で議事録・ToDoを残し、決定事項を流す**。5〜6月中に対応。
- 担当=**小山(サイボウズに詳しい)+寺島**の情報共有チーム。組織図たたき台のチェックを本会議メンバーで回す。

### 2. 青木物件(新規事業 / まだ最終確定前)
- 第一元商方針:**姉崎70人寮 + 松ヶ島25人寮 = 95人・2拠点**。
- **松ヶ島25人**=四畳半旅館・住宅街(青木氏自宅そば)。社員寮として使用(社員・信頼できる卒業生作業員)。**第一元商の社員ルール=一室4.5万円・3食付き**。
- **姉崎70人**=外国人主体。青木の既存作業員は寮費賄い2,500円/日(=7.5万/月)で日本人と差が出るため。第一元商の既存14〜15人+第一寮として55〜56人。
- 物件は**総業が取得**(総額 約1.5〜1.6億)。第一元商の家賃が約150万なら勘弁してもらう。
- **7/1 事業開始**、6月に準備。事業計画は別チームが作成中。**リーダー選定は八木市川コンビに一任**(経験者が入らないと回らない)。会長に最終OKをもらう前提。

### 3. 正栄(しょうえい)寮(会長案件 / 要確認)
- 若松の正栄さん物件に20室空き。会長は「1万円で20人入れろ」と言うが、**電気代で消えるため採算が合わない**。
- **「うちが利益を取れる家賃」を算出する方針**。正栄の家賃(昔80万→今約60万)を土木に再確認し、その水準を基準に。電気代込み1.5〜1.6万円/室で交渉する案。
- 風呂は使わせず**部屋のみ貸し**案。正面棟=正栄、側面リニューアル棟=第一元商で分ける。来週までに**八木市川コンビが固める**。
- 宿舎は **若松120室+共生返還7室+正栄20室=153室**体制に整理。

### 4. 税務・内部統制
- **昨日、雨谷(=雨海税理士。国税OB・元査察チームの長)による模擬査察を実施**。現金出納帳の金種別集計は高評価。
- 指摘:不要書類は処分、**金庫・切手・印紙の棚卸し管理**(分母分子を合わせる)。若松は遠山を責任者として緊張感を持たせる。
- **本部チームが定期的に社内監査**を行う体制を来週までに決める。
- **固定資産税の過払いを発見**:売却済み物件(トップロード=中田町、令和3年11月売却 等)の固定資産税を地商総業が払い続けていた。全70〜80物件を洗い出し、市へ**還付請求**。担当を来週決定。

### 5. 営繕の新規事業・運用
- **高速道路の草刈り・整備(イーシス社経由 / NEXCO)**:千葉北で2名→講習後5〜7人チーム。土日祝休み・通年。社保・外国人可(当初は日本人2名+講習4名)。刈払機等の資格が必要。
- **リフォーム事業の保険に加入**:請負賠償保険(年19,560円)+建設工事保険(年40,040円)=約6万円/年(売上2,000万想定)。

- **営繕チームの拠点を6月から若松へ移籍**、倉庫も浜野→若松へ集約。
- **交通費ルール変更**:通勤と業務移動を分け、距離を毎日報告→規定額で支給。車は八重垣さんの社用車に相乗り(最大2台、運転手当の重複を排除)。
- **下家(しもや?)の置き場整理**:約100万で収まる見込み、275万請求予定(利益約175万)。
