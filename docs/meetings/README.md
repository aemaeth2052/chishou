# 議事録(meetings)

毎日の会議の議事録を構造化して貯め、今後のナレッジベースとして使うためのディレクトリ。
`docs/decisions/`(重大判断の記録)と対になる位置づけ。日々の会議 → ここに蓄積 → 重大判断が出たら decisions に昇格。

## 運用フロー
1. ユーザーが議事録(音声文字起こしの生テキストでも可)を Claude に貼る。
2. Claude が `docs/glossary.md`(用語集・固有名詞辞書)を参照し、固有名詞・社内用語・誤変換を修正する。
3. `_template.md` の定型フォーマット(決定事項 / TODO / 数字 / 論点・保留 / 関連)に構造化する。
4. `docs/meetings/YYYY-MM/YYYY-MM-DD-会議名.md` として保存し、commit & push。
5. 重大判断(投資 > 月商10%、人員 ±10%、新規事業、撤退、提携)が出ていたら `docs/decisions/` に昇格させる。
6. 未完了TODOは、次回以降の関連会議で「前回の宿題」として繰り返し拾う。

## 固有名詞の扱い(重要)
- Claude は御社の固有名詞を完全には知らない。glossary に無い人名・社名は**推測で確定させず**「(要確認: ○○?)」と注記する。
- ユーザーが確定したら `docs/glossary.md` に追記 → 次回から自動で正しく修正される。
- 「議事録を貯める」ことと同じくらい「glossary を育てる」ことが精度に効く。

## ファイル命名
- `docs/meetings/YYYY-MM/YYYY-MM-DD-会議名.md`
- 例: `docs/meetings/2026-05/2026-05-25-経営会議.md`

## テンプレート
新規議事録は `_template.md` をベースに作成する。
