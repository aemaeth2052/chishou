# 議事録: 外国人従業員(技能実習・特定技能)の給与体系見直しに関する法務相談

| 項目 | 内容 |
|---|---|
| 日付 | 2026-06-15 |
| 種別 | 法務相談(労務・組織)/ 重大判断の検討段階 |
| 相談相手 | 顧問弁護士事務所(金原弁護士、川崎弁護士 ※同グループ会社) |
| 出席 | 当社:社長 ほか担当者 / 弁護士:金原・川崎 |
| 所要 | 約30分(時間管理あり、要点のみ) |

---

## 1. 相談の背景・目的

- 当社は建設業。現場作業員を含む全体で約320名、うち外国籍が約80名(技能実習生→特定技能)。**全体の1/4が外国籍**。
- 売上に大きな季節変動。例年 3〜4月の年度末は月商1.5〜1.8億だが、**今期は道路工事等の減少で1億程度**まで落ち込んだ月があった。
- 一方、外国人の人件費は**固定月給(満額支給=仕事がなくても100%支給)**でほぼ固定費化。閑散期・天候不順時に重い。
- **目的:** 日本人と同じ「日給月給(出来高・稼働連動)」に近づけたい。少なくとも休業時の負担を軽くしたい。
- **対象範囲:** 今後の新規入社者だけでなく、**現在在籍中の80名も含めて変えたい**というのが社長の希望。

---

## 2. 弁護士からの結論(先出し)

> **既存従業員の労働条件をマイナス方向(満額支給→日給月給/6割休業手当)に動かすのは、同意書を取っても行政が認めず、計画取消リスクまである。正直、現状の引き下げは厳しい。**
> 現実的な王道は「**新規入社者・切替タイミングからゼロベースで新条件を適用**」。基本給は低めに抑え、出来高・手当・賞与で年収を調整する設計が落とし所。

---

## 3. 論点ごとの整理

### 3-1. 告示(特定技能)の制約 — ここが最大の壁
- 特定技能は**告示**により、給与の払い方に縛りがある。
  - 「**最も近しい働き方をしている日本人と同等水準**」が求められる(単に日給水準を合わせれば良いという話ではない)。
  - 不安定な地位の外国人を**安定的に処遇せよ**という趣旨で出た告示。よって「雨ばかりで仕事がない月は給料が出ない」という日給月給的な運用は、**告示要件を満たさない可能性が高い**。
- 過去に悪質な事例があったため、告示は厳しめ・ガチガチになっている。

### 3-2. 不利益変更の問題(既存者)
- 満額支給という既得の権利を引き下げるのは**労働条件の不利益変更**。
- 裁判所の現在の考え方では、**単に同意書を取るだけでは足りない**:
  - 母国語での説明 → 検討期間の設定 → 質問への回答 → その上で同意取得、という**ステップを踏む必要**。
- 仮に就業規則(6割休業手当)が外国人にも適用できてしまう状態だと、「**実態は満額支給なのに、なぜ6割に下げるのか**」という不利益変更の論点が必ず生じる。**ノーリスクで変えられる状態ではない**。

### 3-3. 就業規則の不備
- 現行の就業規則は**日給月給(日本人)前提**。外国人がどの規定に当てはまるか不明確で、**非常に不安定な状態**。
- **対応:** 外国人専用の就業規則を新設すべき(適用対象を明確化)。働き方・責任範囲・転勤の有無等が日本人と異なるなら、規則を分ける合理性はある。
- **年間休日の齟齬:** 契約書は105日記載だが、就業規則の休日日数を足すと約114日になり**約9日分が休日出勤扱いになっている恐れ**。労働者に有利な就業規則が優先されるため要是正。

### 3-4. 休業手当(平均賃金の60%)
- 6割補償は**労基法上の最低基準**(これ自体は新規なら設定可)。
- ただし平均賃金は**暦日で割る**ため目減りする。
  - 例:日給1.5万円・週休&祝日の人 → 暦割では1日約1万円の補償。**実日給より割り負ける**ケースがある。
- 同じ仕事で「日本人100%・外国人60%」と差を付けると、**同一労働で差が生じる理由**を争われるリスク(グレー)。

### 3-5. 変形労働時間制(1年単位)
- 理論上は使えるが、**おすすめしない**。
  - **年間カレンダーを事前に確定**する制度(例:3〜4月は増やし6月は減らす)。製造ラインのような事前計画型向け。
  - 天候・突発キャンセルで「今日は12h、明日は4h」と**都度動かす制度ではない**。当社の実態に合いにくい。
  - 現行就業規則に変形の記載がなく、**導入には規則変更が必要**。導入自体が不利益変更に当たるかは影響をシミュレーションして判断。
  - **日本人含め同職種は全員適用が必要**(外国人だけ変形は不可。告示の同等性に抵触)。

### 3-6. 行政・管理団体との関係(大前提)
- 労働法の世界で当事者(会社×従業員)が合意しても、**特定技能の受け入れ要件で給与の払い方を否定されれば無意味**。
- **進め方の順序:**
  1. 社内で腹案(スキーム)を作る
  2. **まず管理団体にぶつける**(許認可が通るか)
  3. 管理団体OK → 個別従業員の同意 → 実行
- **リスクの正体:** 行政相談で「ダメ」と言われるだけでなく、**受け入れ計画の取消リスク**がある。だから**勝手に進めるのが最もまずい**。
- 管理団体からは「6割にするのは良い」程度の回答を得ているが、告示の安定性要件からすると**鵜呑みは危険**。
- 外国人実務・行政との直接やり取りは弁護士側も多くは扱っておらず、**実務面は管理団体に一日の長**。腹案ベースで他社事例を確認するのが有効。

---

## 4. 現実的な進め方(王道)

1. **既存80名はマイナス変更を見送る**(不利益変更+計画取消リスク)。
2. **新条件は切替・新規のタイミングで適用する:**
   - 新規入社者(ゼロベースで交渉できる)
   - **技能実習(3年)→特定技能への移行時**(契約結び直し=一旦リセットの余地)
   - 一旦帰国→再入国での再雇用(形式上リセット。ただし**脱法的と見られるグレー**。当社は管理団体がほぼ自社支援&協力的なため余地はある)
3. **給与設計の方向性:**
   - **基本給は低めの安定ベース**(告示の「安定的月給」を満たす最低限)を確保
   - **出来高・各種手当(資格手当 N3 等)・賞与で年収を調整**(稼働良い年は賞与で上乗せ、閑散期は調整)
   - **減額には必ずバーター(代替メリット)を付ける**(賞与・退職金・特定日の昇給等)。一方的減額は不可。
4. **外国人専用就業規則を整備**(まず社労士ベースで作成、弁護士は別見積。適用対象・休日・変形等を明確化)。
5. やりやすい所(休日日数の整合、就業規則整備)から着手し、**日給月給化は最後の最後**。

---

## 5. 留意点・気づき(議論中に出たもの)

- 技能実習→特定技能の移行時、給与を据え置いて申請したら行政から「**次のステップなのになぜ同額か**」と返された経緯あり(+5千円で再申請)。**上げる前提で見られている**ところに引き下げを通すのは一層難しい。
- 本人たちの希望は基本給**28万**水準。現状は基本給22万+手当で実質30万超のケースも。手当は既存手当のため、引き下げ時は**手当をセットで提示**しないと最低限の説得力が出ない。
- 根本デメリットは「**転校空順(=天候・受注減)で稼げない時も満額払う構造**」。雨天時の内職的な作業など、**仕事を作って稼働させる発想**も一案。
- 「1回決めた条件を下げる」のは法律事務所でも同種の難しさ。**安易な引き下げは禁物**。
