## 1. 案件概要

既存のアートヒルズ蘇我(有料老人ホーム、月商1000万、黒字化済み)の運営ノウハウと、本業である建設業の自社施工力を活かし、サービス付き高齢者向け住宅(サ高住)を新規建設する。

「事業拡大 + 一部新規事業」の位置づけ。介護業界内で別業態への展開。

## 5. 議論で出た所見・論点

### 強み
- 建設業 × 介護運営の両方の経験を持つ事業者は珍しく、後発でも勝てる組み合わせ
- アートヒルズが黒字化しており、施設運営ノウハウは実証済み
- 自社施工で建設原価を内製化できれば、競合に対して構造的優位
- 56年積み上げた信用・取引関係(無形資産)

### 懸念・リスク
1. **稼働率は立地が9割**。千葉県内のどこに建てるかで成否が決まる
2. **介護スタッフ確保が最大の壁**。建設の現場作業員引退組をスタッフ化するなら介護資格取得計画が必須
3. **介護報酬・サ高住制度の改正リスク**。10年スパン投資で制度変動を織り込む必要
4. **後継者問題**。20年運営事業を、誰が引き継ぐかが未確定
5. **既存事業との関係**。建設業320名の高齢化と並行で考える必要

### 構造的な気づき
サ高住事業は単なる新規投資ではなく、**次の経営チームの実戦修行の場**として位置づけられる可能性がある。設計段階から後継者候補を関与させ、開業後の運営責任を持たせることで、ハコもの投資を後継者育成と一体化できる。

## 6. 今日の判断: やる方向で詰める(2条件付き)

### 条件1: 数字を詰める(FS実施)

1〜2ヶ月かけて、以下を確定させる。

```
【投資規模】
□ 建物規模(戸数)
□ 立地(商圏)
□ 土地取得 or 自社保有
□ 建築費(自社施工原価ベース)
□ 設備・備品
□ 開業前運転資金
□ 総投資額 = ___ 億円
□ 月商に対する比率 = ___%

【資金調達】
□ 自己資金
□ 借入(政府系/銀行、期間、金利)
□ 借入後の自己資本比率(30%維持できるか)
□ 借入後の手元現預金(月商3ヶ月分維持できるか)

【3シナリオ収益試算】
□ 楽観(入居率95%): 月商 ___ 万円
□ 標準(入居率85%): 月商 ___ 万円
□ 悲観(入居率60%): 月商 ___ 万円
□ 悲観でも会社全体が存続するか
```

### 条件2: 後継者育成計画を一体で作る

```
□ 内勤社員70名から経営幹部候補1〜2名を特定
   - 評価軸: 誠実性、数字を読める、人を動かせる、健康
   - docs/03-organization.md の採用3原則を社内昇格にも適用

□ 候補者をサ高住事業に早期から関与させる
   - 設計・立地選定段階から参加
   - 開業後は運営主担当として責任を持たせる
   - 失敗の許容額を決めて任せる(例: 1000万円までは口を出さない)

□ 親族承継の可能性を明示的に決着させる
   - 50代のうちに対話を完了
   - 親族が継ぐ意思 → サ高住か建設の責任者として役割を分ける
   - 継がない意思 → 文書化して後の紛争を防ぐ

□ 育成期間: 5〜7年(サ高住の黒字安定までと同期)
```
