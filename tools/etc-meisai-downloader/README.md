# ETC利用明細ダウンローダー

ETC利用照会サービス（https://www.etc-meisai.jp/）から、登録している全ETCカード（車両）の
利用明細PDFを、期間指定でまとめてダウンロードするWindows用ツール。

## 前提・注意事項

- **ETC利用照会サービスの[利用規約](https://www.etc-meisai.jp/rules.html)を必ず確認すること。**
  自動アクセスに関する制限がある場合、本ツールの利用はアカウント停止等のリスクを伴う。
  自社カードの明細を自社業務のために取得する用途を想定している。
- 公式APIは存在しないため、ブラウザ（Chromium）を自動操作する方式。
  **サイト側の画面変更があると動かなくなる**ことがある（後述のトラブル対応を参照）。
- ログインIDは1つ、そのIDに複数のETCカードが登録されている構成を想定。
- パスワードを保存する場合、`config.json` に**平文**で保存される。
  PC自体のログインパスワード・ディスク暗号化（BitLocker等）で保護すること。

## セットアップ（初回のみ）

1. [Python](https://www.python.org/downloads/) をインストール
   （インストーラーで「**Add python.exe to PATH**」にチェックを入れる）
2. このフォルダの `setup.bat` をダブルクリック
   （仮想環境の作成・ライブラリ・ブラウザのダウンロードが自動で行われる。5分程度）

## 使い方

1. `run.bat` をダブルクリックして起動
2. ユーザーID・パスワードを入力（「保存する」にチェックすれば次回から不要）
3. 検索期間を指定（「今月」「先月」「昨日」ボタンで一発入力可）
4. PDF保存先フォルダを確認して「実行」

登録カードごとに `カード名_開始日-終了日.pdf` という名前で保存される。
期間内に利用がないカードはスキップされる。

## うまく動かないとき

エラーが出ると `logs/error_日時/` フォルダに**その時の画面のスクリーンショットとHTML**が
自動保存される。これを開発者（Claude）に渡せば、画面構成の変化に合わせて
`downloader.py` の `SELECTORS`（画面部品の定義）を修正できる。

よくある原因:

| 症状 | 対処 |
|---|---|
| 「画面部品が見つかりません」 | サイトの画面変更。logs の内容を添えて修正依頼 |
| 「ログインに失敗しました」 | ID/パスワードの確認。サイトに直接ログインして試す |
| ブラウザがすぐ閉じる・403 | サイト側のbot対策の可能性。「ブラウザの動きを表示する」をONで再実行 |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `app.py` | GUI（画面）。期間指定と実行ボタン |
| `downloader.py` | ブラウザ自動操作の本体。`SELECTORS` に画面部品の定義 |
| `setup.bat` | 初回セットアップ |
| `run.bat` | 起動 |
| `config.json` | 設定の保存先（自動生成。Git管理外） |
| `logs/` | エラー時の画面記録（自動生成。Git管理外） |
