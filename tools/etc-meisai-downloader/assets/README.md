# アプリアイコン

このフォルダに `icon.png` を置くと、アプリのアイコンとして使われます。

## やること

1. アイコン画像を **`icon.png`** という名前でこのフォルダに保存する
   - 推奨: 正方形・1024×1024px 程度・PNG形式
2. それだけ。次回起動時/ビルド時から自動で反映されます

## 反映先

| 場所 | 使うファイル | 生成方法 |
|---|---|---|
| 実行中ウインドウ・タスクバー | `icon.png` | そのまま使用 |
| 配布exe (Windows) のアイコン | `icon.ico` | ビルド時に `icon.png` から自動生成 |

`icon.ico` は `build.py` が `icon.png` から自動生成するため、手動で用意する必要はありません
(生成物なので Git 管理対象外)。
