# 配布手順書

## 構成の概要

| 項目 | 場所 |
|---|---|
| 配布物 | `ETC明細ダウンローダー.zip`（フォルダごとzip。約80MB） |
| 配布物の中身 | `ETC明細ダウンローダー.exe` ＋ `_internal/`（ライブラリ） |
| 配布先 | 社内ファイルサーバーの共有フォルダ |
| 各PCの設定保存先 | `%APPDATA%\ETC明細ダウンローダー\` |
| 各PCのChromium | `%APPDATA%\ETC明細ダウンローダー\browsers\`（初回起動時に自動DL） |
| 各PCのPDF/履歴 | 設定で指定した保存先＋`%APPDATA%\ETC明細ダウンローダー\logs\` |

設定とログは**exeとは別の場所に保存される**ので、フォルダごとの差し替え（アップデート）で設定が消えることはありません。

---

## 管理者(あなた)の作業

### 初回ビルド

1. お手元のWindows PCで `setup.bat` を実行（既に済んでいる想定）
2. `build.bat` を実行
   - PyInstallerが自動インストールされる
   - 5〜10分でビルド完了
3. 出力された **`ETC明細ダウンローダー.zip`** を社内ファイルサーバーの共有フォルダにアップロード

### アップデート時

1. ソースを更新（Gitなどで最新版を取得）
2. `build.bat` を再実行 → 新しい `ETC明細ダウンローダー.zip` ができる
3. 共有フォルダのzipを上書きで差し替え
4. 利用者へ「最新版が出ました。各自でフォルダごと置き換えてください」と通知

## 利用者向け案内文（コピペ用）

> ETC利用明細ダウンローダーをご利用ください。
>
> ### セットアップ（初回のみ）
> 1. 共有フォルダ `\\<サーバー名>\<共有名>\ETC明細ダウンローダー\` から `ETC明細ダウンローダー.zip` を**ご自身のPCのデスクトップまたはドキュメント**にコピーしてください
> 2. zipを右クリック→「すべて展開」で解凍
> 3. 展開してできたフォルダ内の **`ETC明細ダウンローダー.exe`** をダブルクリック
>    - 初回は「Windowsによって PC が保護されました」が出る場合があります。**「詳細情報」→「実行」**で起動できます
>    - 初回起動時にブラウザ(Chromium、約170MB)を自動ダウンロードします。完了まで数分お待ちください
> 4. 起動したら「設定」タブで ETC利用照会サービスのID/パスワード、保存先、車両を登録してください
>
> ### 毎日の使い方
> - フォルダ内の `ETC明細ダウンローダー.exe` をダブルクリック
> - 画面上から順に「検索期間 → 検索対象 → (必要なら)番割全体表示から取込」を設定して「検索開始」
>
> ### アップデート
> 共有フォルダ内のzipが新しくなったら、現在使っているフォルダを削除して、新しいzipを同じように展開してください。登録した車両情報や設定は引き継がれます。

## トラブルシューティング

### 「WindowsによってPCが保護されました」と出て起動できない
PyInstaller製の自作ソフトは無署名なのでWindows SmartScreenが警告を出します。これは正常です。

**対処**: 警告画面の **「詳細情報」** リンクをクリック → **「実行」** ボタンを押す。一度実行すれば次回からは出ません。

抜本対策として「コード署名証明書」を購入する選択肢もありますが（年4〜10万円）、社内配布なら上記の手順で運用するのが一般的です。

### Windows Defender / ウイルスバスター等で警告される
PyInstaller製exeは誤検出されることがあります。**対処**:
1. 当該ソフトの「ホワイトリスト」「除外設定」に exe または展開フォルダを追加する
2. 情シス担当に「社内製ツールです」と申請

### 初回起動時にブラウザのダウンロードが失敗する
社内プロキシでブロックされている可能性があります。**対処**:
- 情シス担当に `playwright.azureedge.net` への接続許可を依頼
- それが難しい場合は、別途Chromiumを手動でセットアップする方法もあるので管理者にご相談ください

### 「検索開始」を押してもしばらく反応がない
初回起動時はブラウザのダウンロード待ちです。ログ欄に進捗が出るのでお待ちください。

### 設定や車両リストを別のPCに引き継ぎたい
利用者側操作:
1. `%APPDATA%\ETC明細ダウンローダー\config.json` をコピー
2. または「設定」タブの「CSVに書き出す」で車両リストだけ書き出し、別PCで「CSVを読み込む」

### ソフトが動かなくなった
1. 「設定」タブの **「開く」** で保存先フォルダを開けます
2. `%APPDATA%\ETC明細ダウンローダー\logs\` の `error_*` フォルダ内のスクリーンショットとHTMLを管理者(あなた)にご共有ください
3. サイト側の画面構成が変わっている可能性があります
