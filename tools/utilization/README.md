# 作業員稼働率ツール

Hksの「番割予定表」と社員名簿CSVを突き合わせ、**営業所ごとの作業員稼働率**を出すツール。
開いている番割が複数（例: 5営業所）あれば、(営業所, 日付)ごとに別々に集計する。

```
分母   = 番割に名前のある自営業所社員（現場 ＋ 待機/休み枠）
分子   = そのうち外貨を産む現場に出た人
稼働率 = 分子 ÷ 分母
```

> Hksと同じPCで実行すること（番割ウィンドウを UI Automation で読むため）。全画面化は不要。

## セットアップ（初回のみ）

1. [Python](https://www.python.org/downloads/) をインストール（「Add python.exe to PATH」にチェック）
2. このフォルダの `setup.bat` をダブルクリック（必要ライブラリを入れる）

## 使い方（GUI・おすすめ）

`utilization_app.bat` をダブルクリックで起動。タブ構成:

| タブ | 役割 |
|---|---|
| **集計** | 名簿を指定 →「番割から集計する」→ **対象の番割を選ぶダイアログ**（営業所×日付。既定は全選択）→ 営業所ごとの稼働率を一覧表示。名簿指定は記憶される |
| **除外設定** | 外貨を産まない顧客／現場のキーワード（部分一致）と、分母から除く事務所スタッフ（コード/氏名）を編集・保存 |
| **色判定** | 番割の**氏名の背景色**で自社/他社を判定。「番割の色を読み取る」で検出色を一覧表示し、各色に「自社／他営業所応援／対象外」を割り当て→`worker_colors.json` に保存 |
| **対照表** | 取りこぼし候補を一覧表示。行を選び「自社／他営業所／対象外」を割り当て（推奨コードが自動入力）。`name_aliases.json` に保存 |
| **履歴** | `utilization_history.csv` の推移を表示 |
| **Google連携** | サービスアカウント設定。集計時にスプレッドシートへ自動upsert |

集計を押すと、レポート・明細・履歴・取りこぼしの各ファイルも自動で書き出される。

## 名簿の置き方

Hksから社員名簿をCSV（コード,名称,フリガナ,営業所,区分,備考,…,在,… の形式。Shift-JIS）で書き出す。
営業所ごとに分かれていてよい。

- **`roster` フォルダ**を作って各営業所のCSVを入れる（中の `*.csv` を全部読む）← 5営業所はこれが楽
- 1ファイルなら `roster.csv` として置く、または `utilization.bat` にドラッグ＆ドロップ

各番割は見出しの営業所で**名簿の「営業所」列**を照合し、自動的に正しい名簿を使う。

## 区分の判定

作業員を **自営業所 / 他営業所応援 / 集計対象外** の3区分に分ける。判定はハイブリッドで、
次の優先順位で決まる。

1. **手動補正**（`name_aliases.json`）… 最優先
2. **氏名の背景色**（`worker_colors.json`）… 色が登録済みなら**主判定**
3. **バッジ＋名簿CSV**（従来）… 色が未登録/未採取のときのフォールバック兼裏取り

| 区分 | 色判定（主） | 従来判定（裏取り/フォールバック） | 扱い |
|---|---|---|---|
| **自営業所** | 背景色が「自社」 | 自営業所バッジ or 名簿一致 | 稼働率の分母・分子 |
| **他営業所応援** | 背景色が「他営業所」 | 自営業所以外の営業所バッジ | 別集計（借りた人工） |
| **集計対象外** | 背景色が「対象外」 | バッジ無し&自営業所の名簿に無い | カウントしない |

- 色と従来判定（他営業所バッジ or 名簿一致）が**食い違う行**は、取りこぼし候補に「要確認」で出る。
- 番割の見出しの営業所が「自営業所」。バッジ（蘇我/若松/八幡/都賀/加曽利/宮崎 等）は色が
  未設定のときのフォールバックに使う。

### 色判定の設定手順

1. 番割を Hks で開く
2. GUIの **「色判定」タブ → 「番割の色を読み取る」**（採色は **PrintWindow** 主・画面キャプチャ副。
   番割が最前面でなくても、PrintWindow が効けば隠れていても拾える）
3. 検出された各色（実際の背景色付きで表示）に **自社/他営業所応援/対象外** を割り当て→**保存**
4. 以降の集計は、その色で自社/他社を判定する（未割当の色はバッジ＋名簿にフォールバック）

> CLI/手書き派は `worker_colors.example.json` を `worker_colors.json` にコピーし、`inspect_workers.bat`
> が吐く `workers_colors.txt` の hex を見て編集してもよい（雛形 JSON も出力される）。
> `tolerance` は背景色の許容差（R+G+B各差の合計）。番割の色は単色なので 40 前後。

> **採色できない（全員「背景色取得不能」）とき**: 画面の拡大率が 100% を超えていると、座標系の
> ズレで色が拾えないことがある。GUIは起動時にDPI対応を有効化するので、**GUIを再起動**すれば直る
> ことが多い。なお採色は氏名セルを実際に試し打ちして検証し、PrintWindowで取れなければ自動で
> 画面キャプチャ採色に切り替える。それでも全滅する場合は番割を最前面・全表示にして再試行を。

- **番割の「待機」「休み」枠の人も分母に入れる**（外貨にも管理費にも入れない＝非稼働）。
  待機/休み枠は見出しが「待機」「休み/留守」の2列で並び、氏名は通常現場と違ってブロック
  直下のテキストに入る別構造なので、専用処理（`standby_workers`）で拾い、x座標で待機/休みを
  振り分ける。さらに、その枠はこの営業所の自前要員なので、**バッジ無し＆名簿未照合でも
  自営業所として分母に算入**する（名簿未照合なら「確認推奨」に出してコード補正を促す）。
- **名簿にいても番割に名前がどこにも無ければ分母に入れない**。
- **自社タグが付けば名簿に無くても無条件で自社**として計上（同時に「確認推奨」にも出る）。
- 自営業所から他営業所へ貸し出した人は自営業所の番割に自社タグ付きで出る → 稼働として算入し
  「うち他営業所へ貸出」として内訳表示。

## 例外（除外）キーワードの管理

`utilization_settings.json`（`*.example.json` をコピーして編集）。いずれも**部分一致**。

```json
{
  "exclude_customer_keywords": ["第一元商", "宮崎興業"],
  "exclude_site_keywords": ["送迎", "寮", "清掃"],
  "non_field_staff": ["2229935"]
}
```

- `exclude_customer_keywords` / `exclude_site_keywords` … 顧客名／現場名にこの語を含む現場を管理費
- `non_field_staff` … 事務所スタッフ・ダミー（社員コード or 氏名）

## 対照表（外国人ニックネーム等の補正）

`name_aliases.json`（`*.example.json` をコピー）。番割の表示名 → 名簿コード／`other`／`ignore`。
自動判定で取りこぼした人だけ書けばよい。GUIの「対照表」タブからも登録できる。

```json
{ "ジョン": "2232353", "コバル": "other" }
```

## 出力ファイル

| ファイル | 内容 |
|---|---|
| `utilization_report.txt` | 営業所ごとの稼働率と内訳 |
| `utilization_detail.csv` | 作業員ごとの判定明細（営業所・バッジ・**背景色**・区分・**判定備考**付き） |
| `utilization_history.csv` | 日次履歴（日付×営業所ごとに1行。同じ日付・営業所は上書き） |
| `utilization_review.csv` | 取りこぼし候補（確認推奨／要確認、推奨コード付き） |

## Googleスプレッドシート連携（サービスアカウント）

GUIの「Google連携」タブで設定。集計のたびに (日付×営業所) をシートへ上書き/追記する。

1. Google Cloud でプロジェクト作成 →「Google Sheets API」を有効化
2. サービスアカウント作成 → 鍵を JSON でダウンロード
3. 対象シートを、そのアカウントのメール（`…iam.gserviceaccount.com`）に「編集者」で共有
4. タブに JSONパスとシートURLを入れて「接続テスト」→「保存」、「集計時に更新」にチェック

JSONキーは資格情報。PC内で安全に保管（設定にはパスのみ保存）。

## CLIで使う

```
python utilization.py --roster roster            # roster フォルダ内の全CSV
python utilization.py --roster A.csv B.csv        # 個別指定
python utilization.py --roster roster --inspect workers_inspect.txt   # 検証(番割を読まない)
```

## 調査ツール

`inspect_workers.bat` … 番割の作業員・氏名背景色・営業所バッジをダンプ（区分判定の確認用）。

`inspect_standby.bat` … 「待機」「休み」枠の画面構造（見出し・ブロックの入れ子・氏名セル位置）を
`standby_dump.txt` にダンプ（待機/休みが分母に拾えないときの調査用）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `utilization.py` | 集計ロジック（CLIでも単体実行可） |
| `utilization_app.py` / `.bat` | GUI |
| `utilization.bat` | CLI起動 |
| `hks_reader.py` | 番割予定表の読み取り（UI Automation）。`read_all_assignments` で全作業員 |
| `worker_color.py` | 氏名の背景色の採取（PrintWindow主・画面副）と色→区分マップ |
| `sheets_sync.py` | 履歴をGoogleスプレッドシートへupsert |
| `inspect_workers.py` / `.bat` | 番割の調査ツール（背景色クラスタ＋設定の雛形を出力） |
| `name_aliases.example.json` | 対照表のひな型 |
| `worker_colors.example.json` | 色→区分マップのひな型 |
| `utilization_settings.example.json` | 除外設定のひな型 |
| `setup.bat` / `requirements.txt` | 初回セットアップ |

> `hks_reader.py` は ETC明細ダウンローダー（`../etc-meisai-downloader/`）と共通の番割読み取り
> モジュール。あちらにも同名ファイルがあり、両方を編集したときは内容を揃えること。
