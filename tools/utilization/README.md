# 作業員稼働率ツール

Hksの「番割予定表」を読み取り、**営業所ごとの作業員稼働率**を出すツール。
開いている番割が複数（例: 5営業所）あれば、(営業所, 日付)ごとに別々に集計する。
判定は氏名セルの背景色＋手動補正のみ（名簿CSVは使わない）。

```
分母   = 番割に名前のある自営業所社員（現場 ＋ 待機/休み枠）
分子   = そのうち外貨を産む現場に出た人
稼働率 = 分子 ÷ 分母
```

> Hksと同じPCで実行すること（番割ウィンドウを UI Automation で読むため）。全画面化は不要。

## セットアップ（初回のみ）

1. [Python](https://www.python.org/downloads/) をインストール（「Add python.exe to PATH」にチェック）
2. このフォルダの `setup.bat` をダブルクリック（必要ライブラリを入れる）

## 使い方（GUI・おすすめ）

`utilization_app.bat` をダブルクリックで起動。タブ構成:

| タブ | 役割 |
|---|---|
| **集計** | 「番割から集計する」→ **対象の番割を選ぶダイアログ**（営業所×日付。既定は全選択）→ 営業所ごとの稼働率を一覧表示（2営業所以上そろえば**全社合計**行も出る）。行を**ダブルクリック**すると作業員ごとの明細が開き、その場で自社/他営業所/対象外を割当できる（保存と同時に**番割を読み直さず即再集計**）。「スナップショットから再計算」で過去の保存データからも集計できる |
| **除外設定** | 外貨を産まない顧客／現場のキーワード（部分一致）と、分母から除く事務所スタッフ（コード/氏名）を編集・保存 |
| **色判定** | 番割の**氏名の背景色**で自社/他社を判定。「番割の色を読み取る」で検出色を一覧表示し、各色に「自社／他営業所応援／対象外」を割り当て→`worker_colors.json` に保存 |
| **対照表** | 取りこぼし候補を一覧表示。行を選び「自社／他営業所／対象外」を割り当て（即再集計）。`name_aliases.json` に保存 |
| **履歴** | `utilization_history.csv` の推移を表示（営業所別の稼働率折れ線グラフ・直近30日つき） |
| **Google連携** | サービスアカウント設定。集計時にスプレッドシートへ自動upsert |

集計を押すと、レポート・明細・履歴・取りこぼしの各ファイルも自動で書き出される。
対照表・色判定・除外設定を保存すると、直前の読み取り結果から**即座に再集計**される
（番割の読み直し・採色のやり直しは不要）。

## 2つの率

| 指標 | 式 | 見るもの |
|---|---|---|
| **稼働率** | 外貨 ÷ 出勤（現場＋待機＋休み） | 人員規模に対する売上効率 |
| **実働率** | 外貨 ÷（出勤 − 休み） | 出られる人をどれだけ外貨現場に出せたか（配車・営業の実力）。待機は分母に残す |

レポート末尾には**営業所間の応援マトリクス**（借り手×貸し手の人数）も出る。

## スナップショット（生データの控えと遡り再計算）

集計のたびに、読み取った生の割当（誰が・どこに・どの背景色で）を
`snapshots/日付_営業所.csv` に自動保存する。番割が画面から消えた後でも、
色・対照表・除外設定を直してから **GUIの「スナップショットから再計算」** または
`python utilization.py --snapshot`（snapshots/ 全部）で過去分を計算し直せる。
同じ（営業所, 日付）は最新の読み取りで上書き。

## 毎朝の自動集計（無人運転）

`install_autorun.bat` を実行すると、タスクスケジューラに毎日の自動集計を登録できる
（時刻は既定 08:00）。実行時刻に **Hksで番割を開いたままにしておく** こと。
結果は通常どおり履歴・スナップショットに残り、Google連携を設定済みなら
スプレッドシートも更新される（`autorun.bat` は `utilization.py --gsheet` を呼ぶだけ）。
ログは `autorun.log`。解除は `schtasks /Delete /TN "UtilizationAutoRun" /F`。

## 区分の判定（氏名の背景色で行う）

作業員を **自営業所 / 他営業所応援 / 集計対象外** の3区分に分ける。判定は
**氏名セルの背景色（`worker_colors.json`）と手動補正（`name_aliases.json`）だけ** で行う。
名簿CSVは使わない（在籍者の移り変わりが激しく参考にならないため廃止）。

判定の優先順位:

1. **手動補正**（`name_aliases.json`）… 最優先
2. **氏名の背景色**（`worker_colors.json`）

| 区分 | 条件（背景色） | 扱い |
|---|---|---|
| **自営業所** | 「自社」に割り当てた色（例: 白） | 稼働率の分母・分子 |
| **他営業所応援** | 「他営業所応援」に割り当てた色 | 別集計（借りた人工） |
| **集計対象外** | 「対象外」に割り当てた色 | カウントしない |

- 背景色が **どの色にも割り当てられていない／採色できなかった** 人は、既定で **対象外** にし、
  取りこぼし候補に「要確認」で出す（本当は自社の白セルなら『色判定』タブで色を登録すれば拾える）。
- 色判定が**未設定**だと全員が対象外になる（レポート冒頭に警告を出す）。

### 色判定の設定手順

1. 番割を Hks で開く
2. GUIの **「色判定」タブ → 「番割の色を読み取る」**（採色は**ウィンドウを一瞬前面に出して画面
   キャプチャ**＝実際に見えている色を読む。隠れている場合は PrintWindow にフォールバック）
3. 検出された各色（実際の背景色付きで表示）に **自社/他営業所応援/対象外** を割り当て→**保存**
   - 同じ色の濃淡で複数行に割れる場合は **許容差を上げて読み直す** と1色に集約される
   - 細かい濃淡は割り当て不要（未割当は対象外。要確認に出るので後から拾える）
4. 以降の集計は、その色で自社/他社を判定する

> CLI/手書き派は `worker_colors.example.json` を `worker_colors.json` にコピーし、`inspect_workers.bat`
> が吐く `workers_colors.txt` の hex を見て編集してもよい（雛形 JSON も出力される）。
> `tolerance` は背景色の許容差（R+G+B各差の合計）。番割の色は単色なので 40 前後。

> **採色できない（全員「背景色取得不能」）とき**: 画面の拡大率が 100% を超えていると、座標系の
> ズレで色が拾えないことがある。GUIは起動時にDPI対応を有効化するので、**GUIを再起動**すれば直る
> ことが多い。採色はウィンドウを一瞬前面に出して画面キャプチャするのが基本で、隠れている場合は
> PrintWindow にフォールバックする。それでも全滅する場合は番割を最前面・全表示にして再試行を。

- **番割の「待機」「休み」枠の人も分母に入れる**（外貨にも管理費にも入れない＝非稼働）。
  待機/休み枠は見出しが「待機」「休み/留守」の2列で並び、氏名は通常現場と違ってブロック
  直下のテキストに入る別構造なので、専用処理（`standby_cells`）で拾い、x座標で待機/休みを
  振り分ける。その枠はこの営業所の自前要員なので、**背景色に関係なく自営業所として分母に算入**する。

## 例外（除外）キーワードの管理

`utilization_settings.json`（`*.example.json` をコピーして編集）。いずれも**部分一致**。

```json
{
  "exclude_customer_keywords": ["第一元商", "宮崎興業"],
  "exclude_site_keywords": ["送迎", "寮", "清掃"],
  "non_field_staff": ["2229935"]
}
```

- `exclude_customer_keywords` / `exclude_site_keywords` … 顧客名／現場名にこの語を含む現場を管理費
- `non_field_staff` … 事務所スタッフ・ダミー（社員コード or 氏名）

## 対照表（外国人ニックネーム等の補正）

`name_aliases.json`（`*.example.json` をコピー）。番割の表示名 → 割当先。
自動判定（背景色）で取りこぼした人だけ書けばよい。GUIの「対照表」タブ・明細ウィンドウからも登録できる。

| 割当先の値 | 意味 |
|---|---|
| `home` | 自社 |
| `other` | 他営業所応援 |
| `ignore` | 集計対象外 |

過去の形式（値が社員コードの数字）もそのまま「自社」として有効。

```json
{ "ジョン": "home", "コバル": "other" }
```

## 出力ファイル

| ファイル | 内容 |
|---|---|
| `utilization_report.txt` | 営業所ごとの稼働率と内訳 |
| `utilization_detail.csv` | 作業員ごとの判定明細（営業所・バッジ・**背景色**・区分・**判定備考**付き） |
| `utilization_history.csv` | 日次履歴（日付×営業所ごとに1行。稼働率%・実働率%。同じ日付・営業所は上書き。旧形式は自動移行） |
| `utilization_review.csv` | 取りこぼし候補（確認推奨／要確認。同姓同名が同じ番割に複数行出た場合もここに出る） |
| `snapshots/*.csv` | 読み取った生の割当の控え（遡り再計算用。営業所×日付ごと） |
| `autorun.log` | 自動実行（タスクスケジューラ）のログ |

## Googleスプレッドシート連携（サービスアカウント）

GUIの「Google連携」タブで設定。集計のたびに (日付×営業所) をシートへ上書き/追記する。

1. Google Cloud でプロジェクト作成 →「Google Sheets API」を有効化
2. サービスアカウント作成 → 鍵を JSON でダウンロード
3. 対象シートを、そのアカウントのメール（`…iam.gserviceaccount.com`）に「編集者」で共有
4. タブに JSONパスとシートURLを入れて「接続テスト」→「保存」、「集計時に更新」にチェック

JSONキーは資格情報。PC内で安全に保管（設定にはパスのみ保存）。

## CLIで使う

```
python utilization.py                             # 開いている番割を全部集計
python utilization.py --inspect workers_inspect.txt   # 検証(番割を読まない)
python utilization.py --snapshot                  # snapshots/ 全部から遡り再計算
python utilization.py --snapshot snapshots/2026-07-03_都賀.csv   # 個別指定
python utilization.py --gsheet                    # 集計後にスプレッドシートも更新
```

## 調査ツール

`inspect_workers.bat` … 番割の作業員・氏名背景色・営業所バッジをダンプ（区分判定の確認用）。

`inspect_standby.bat` … 「待機」「休み」枠の画面構造（見出し・ブロックの入れ子・氏名セル位置）を
`standby_dump.txt` にダンプ（待機/休みが分母に拾えないときの調査用）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `utilization.py` | 集計ロジック（CLIでも単体実行可） |
| `utilization_app.py` / `.bat` | GUI |
| `utilization.bat` | CLI起動 |
| `hks_reader.py` | 番割予定表の読み取り（UI Automation）。`read_all_assignments` で全作業員 |
| `worker_color.py` | 氏名の背景色の採取（前面化＋画面キャプチャ主・PrintWindow副）と色→区分マップ |
| `sheets_sync.py` | 履歴をGoogleスプレッドシートへupsert |
| `inspect_workers.py` / `.bat` | 番割の調査ツール（背景色クラスタ＋設定の雛形を出力） |
| `name_aliases.example.json` | 対照表のひな型 |
| `worker_colors.example.json` | 色→区分マップのひな型 |
| `utilization_settings.example.json` | 除外設定のひな型 |
| `autorun.bat` / `install_autorun.bat` | 毎朝の自動集計（タスクスケジューラ登録） |
| `setup.bat` / `requirements.txt` | 初回セットアップ |

> `hks_reader.py` は ETC明細ダウンローダー（`../etc-meisai-downloader/`）と共通の番割読み取り
> モジュール。あちらにも同名ファイルがあり、両方を編集したときは内容を揃えること。
